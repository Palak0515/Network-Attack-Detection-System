# Network-Attack-Detection-System

## Project Description

This project is a Machine Learning-based Network Attack Detection System developed to detect malicious network traffic using the kddcup.data_10_percent dataset. The application is built using Python, Flask, and MySQL. It preprocesses network traffic data, classifies it as Normal or Attack, supports both manual input and CSV file upload, and stores the prediction results in a MySQL database.

## Features

* Detects normal and malicious network traffic.
* Supports manual input and CSV file upload.
* Stores prediction results in a MySQL database.
* Simple and user-friendly Flask web interface.
* Uses a trained Machine Learning model for prediction.

## Dataset

This project uses the **kddcup.data_10_percent** dataset to train and test the Machine Learning model for network attack detection.

## How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Create the MySQL database using the provided SQL file.
4. Update the database configuration in the project.
5. Run `app.py`.
6. Open the application in your browser.
